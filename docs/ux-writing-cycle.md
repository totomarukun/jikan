# UXライティング & UI磨き サイクル (自動運用)

## ゴール (達成条件)
全画面のUI文言が、上級者が触って違和感のない自然さに到達する。具体的に:
1. **アルゴリズム用語・開発者語をユーザーの言葉に**: 「合成」「推移律」「相対位置の差」「n=支持本数」「正則化」等を、使う人の言葉(「使った人の比較から」「データが少なめ」等)に置き換える。
2. **冗長な注記をUIで代替**: 長い説明文を、アイコン/視覚的手がかり/必要時だけ開く補足(?トグル)に置き換える。一目で分かるなら言葉で説明しない。
3. **トーンと用語の一貫**: 「対決/比較/A/B」「相対マップ/用具マップ」等の用語をブレなく統一。敬体・簡潔・卓球愛のあるトーン。
4. **ブランドガイド遵守**: 「絶対」「No.1」「最強」等の誇大表現は使わない(企画書10章)。誠実な不確実性表現(集計中・参考程度)は残すが、簡潔に。
5. 独立評価(UXライター視点)で「違和感のある文言」「過剰説明」の指摘が実質ゼロになる。

## 原則 (執筆ガイド)
- 主語は「あなた/使った人/みんな」。仕組みでなく価値を語る。
- 1文1メッセージ。括弧の入れ子・専門記号(A>B 等)を本文に置かない。
- 数値の意味は凡例やツールチップに寄せ、本文を短く。
- 空状態は次の一歩を1つだけ示す。
- ラベルは名詞で短く。ボタンは動詞で具体的に。

## サイクル
監査(UXライター独立評価) → 指摘を文言修正/UI代替 → 再監査 → ゴールまで反復。

- 機能名: 「用具マップ」(相対的な位置を見る画面)。本文で仕組みを指すときは「みんなの比較から推定した位置」。
- ユーザーの行為: 「比較する」。蓄積データの単位は「比較」。公開の集計画面名は「対決」。
- 体感の言葉: 「両方使った人の声」。
- 信頼度: 「データが少なめ(参考)」/「データが十分」。
